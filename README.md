# Rail Runner 3D 🚂

一款**第三人称无尽跑酷**小游戏 —— 单个 `index.html` 文件，内嵌 CSS 与原生 JavaScript，使用 Canvas 渲染，**零外部依赖**（无图片、无框架、无网络请求）。

## 玩法

- 主角在**三条平行铁轨**上自动向前奔跑，场景向玩家滚动形成前进感。
- `← / →`（或 `A / D`）切换车道，切换为平滑插值；`↑ / 空格 / W` 跳跃越过矮栏；`↓ / S` 翻滚下滑钻过悬空横杆；移动端支持**四向滑动手势**。
- 三类障碍在三条车道随机生成：
  1. **大型列车**（静止 / 迎面高速驶来）——占满整条车道，只能变道躲避；
  2. **地面矮栏**——需要跳跃；
  3. **空中横杆**——需要翻滚下滑。
- **可通行性保证**：任意时刻最多封锁两条车道，始终保留至少一条可通行车道；生成间距随当前速度自适应。
- 金币沿车道成串生成；周期性刷新道具：**磁铁**（自动吸附金币）、**弹力鞋**（跳跃更高）、**护盾**（短时无敌并加速），HUD 显示剩余时间。

## 画面

- 伪 3D 透视：铁轨向远处消失点汇聚、物体近大远小；两侧程序化生成建筑、灯柱、涂鸦墙并循环滚动；天空 / 地面 / 太阳 / 天际线均为渐变几何图形，色彩明快。
- 含开始页、游戏中 HUD（分数 / 金币 / 当前速度）、暂停与结算面板；最高分通过 `localStorage` 持久化，支持一键重开。
- 使用 `requestAnimationFrame` + 固定步长累加器做帧时间补偿，不同刷新率下手感一致。

## 运行

直接用浏览器打开 `index.html` 即可；也可用任意静态服务器托管。

```bash
git clone https://github.com/daoge96/rail-runner-3d.git
cd rail-runner-3d
# 直接双击 index.html，或：
python3 -m http.server 8080   # 然后访问 http://localhost:8080
```

## 计分

`得分 = 奔跑距离 × 倍率（随速度提升）+ 金币数 × 5`，命中障碍即结束。

## 技术要点

- 世界坐标 `x`=横向车道、`y`=离地高度、`z`=前方；玩家固定在 `z=0`，物体向 `-z` 滚动。
- 针孔相机投影 `sx = cx + f·(x−camX)/dz`、`sy = cy − f·(y−camY)/dz`，按深度降序排序绘制。
- 碰撞为 AABB 判定，并叠加角色当前跳跃高度与翻滚后的身高，因此“跳矮栏 / 滚横杆 / 撞列车”逻辑自洽。
